# Tremor

Tremor is a prototype for movement screening. It is a screening aid, not a medical diagnosis.

## Deploy to GitHub Pages
The repository must contain the app source at its root (including `package.json`, `src/`, `vite.config.ts`, and `.github/workflows/deploy-pages.yml`). The workflow builds the static app and publishes it to GitHub Pages.

If this repository contains only this setup file, download the prepared source ZIP from the project chat, extract it, and upload all of its contents to the repository root. Do not upload the outer ZIP as a substitute for the source files.

Once the source files are committed, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. Then check **Actions** for the deployment result.

The expected URL is https://stejus2010.github.io/tremor/.

## Important
This is a prototype and must not be used to diagnose Parkinson's disease or any other condition. A clinician must interpret screening results.
